# 港调班次复盘

在正式计划生成前，已经发布并生效的横风或低能见度预警先剔除相应泊位的时间格。不同泊位轴线不同，同向风对进港影响不同。告警中的未来撤销不参与当前分析。

占泊估计附两段滚动回放，每段用截止前结案训练，对后续实际结案评估中心误差、覆盖和上界超出程度。不同 `k` 的比较独立执行，按航线显示空白折。

泊位顾问可查看岸桥晚修或港池清障情景下换泊、转待办和冷藏箱保障费差额。不同情景不覆盖当前计划。实际装卸签报再按版次、开离泊与作业时间核对每台岸桥每小时箱量，单独保留未签和未登记回执。

承诺离泊在本班开班截面签出：宽放按开班前结案航次滚动回测校准，航线样本不足回退全港统一口径；已发出承诺保留至原离泊分钟，后续航次自其后安排。同一班次以相同输入重跑，承诺与档期逐笔一致，可按承诺指纹对照。
